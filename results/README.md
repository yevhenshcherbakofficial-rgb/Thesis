## Experimental setup

- Runs: 107 ({'simulator': 35, 'sample': 32, 'workload': 25, 'atomic': 15}); split train/val/test = 60/11/36 runs, 2063/323/1279 processes.
- Split: by run, in time order (earliest 70% of runs -> train, last 15% of those -> validation, latest 30% -> test). Families in `holdout_families` are test-only.
- Holdout (unseen) families: ['LummaStealer', 'njrat'].
- Decision thresholds: chosen on the validation set at FPR <= 0.001, applied unchanged to test.
- Feature window: 30 s after process start; time to detection uses [10, 30] s windows.
- Guest: Windows 11 Pro 26300 (VirtualBox 7.2.22), Sysmon with sysmon-modular `sysmonconfig-excludes-only.xml`, Defender and UAC off, isolated internal network with a DNS/TCP sink VM (10.0.0.2).
- Labels: the scenario launcher process, all its descendants and any process it injected into (CreateRemoteThread) are malicious in malicious runs; everything else is benign. In sample and Atomic runs the launcher itself only stages the payload and is excluded from the dataset (its descendants stay malicious). Only processes that start during the observation window (have a ProcessCreate event) are included.
- Not used as features: image path location and file names (every real sample is launched from Downloads, no benign workload is - a collection artefact, not behaviour).
- Software: Python 3.11.9, scikit-learn 1.9.1, xgboost 3.2.0, torch 2.6.0+cu124, shap 0.51.0.
